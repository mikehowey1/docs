## What is AI Streams?

AI Streams is a GPU cluster monitoring and management platform built on the same Streams infrastructure as Hash Streams. Where Hash Streams is designed around ASIC miners, AI Streams is purpose-built for GPU nodes: it monitors cluster health, manages workload scheduling, optimizes power draw, and provides usage analytics for AI/ML training runs, inference deployments, rendering farms, and GPU mining operations.

Both products share the same agent architecture, the same data pipeline, and the same platform account. If you run both ASIC miners and GPU clusters you manage them from a single dashboard.

## How AI Streams relates to Hash Streams

Both products are part of the Dune Digital **Streams** platform:

| | Hash Streams | AI Streams |
|---|---|---|
| **Compute type** | ASIC miners (SHA-256, Scrypt, etc.) | GPU nodes (NVIDIA, AMD) |
| **Primary use** | Bitcoin / altcoin mining operations | AI/ML, rendering, GPU mining |
| **Agent** | Same binary, configured for ASIC scanning | Same binary, configured for GPU/CUDA discovery |
| **Curtailment** | Stops or throttles ASICs | Throttles GPU power limits or pauses jobs |
| **Dashboard** | Mining control, PDU control, earnings | Cluster monitor, job queue, usage analytics |
| **Pricing** | Pay As You Go or Business | Pay As You Go or Business |

If you already use Hash Streams, you can add AI Streams to the same account and manage both from the same organization and billing setup.

## Getting started with AI Streams

The setup process mirrors Hash Streams:

<Steps>
  <Step title="Create a site (or reuse an existing one)">
    AI Streams sites work the same as Hash Streams sites. If your GPU cluster is co-located with your ASIC miners, you can use the same site and deploy a second agent configured for GPU discovery.
  </Step>
  <Step title="Download and install the agent">
    Download the agent from **Infrastructure → Agents → Download agent** in your dashboard. The same agent binary supports both ASIC and GPU monitoring — the mode is configured through the agent's network segment settings.
  </Step>
  <Step title="Register the agent">
    Generate a registration token from **Infrastructure → Agents**, same as Hash Streams. The token binds the agent to your organization and site.
  </Step>
  <Step title="Configure GPU network segments">
    Add network segments pointing at the subnets where your GPU nodes are reachable. The agent will discover nodes and begin reporting telemetry.
  </Step>
</Steps>

## Pricing

AI Streams uses the same usage-based pricing as Hash Streams — you pay for the telemetry data your agent uploads.

| Plan | Base price | Data rate |
|---|---|---|
| Pay As You Go | $0 / month | $0.018 / MB |
| Business | $149 / month | $0.015 / MB |

Both plans include 200 MB of welcome credits. The Business plan unlocks automated curtailment (including GPU power throttling), unlimited agents, advanced analytics, and priority support.
